## V2.1
- إعادة جميع صفحات الإدارة الرياضية داخل هيكل SAH.
- إضافة مؤشر الأداء الرياضي بفصل كامل بين الطلاب والطالبات بدون دمج.
- ربط بيانات المنح كاملة من Excel: 224 طالبًا و79 طالبة.

- إضافة البطولات الرياضية، التحليل والمقارنة، سجل العمليات، الطلبات، وبوابة الطالب.
- تنظيم طلبات الطلاب حسب الجهة المستقبلة: الإدارة الرياضية أو الأنشطة الطلابية.
- تجهيز المشروع للرفع المباشر على GitHub Pages.


## V8 — Evidence Center & Scholarship Criteria
- Added updated scholarship criteria and conditions (Arabic/English).
- Added Evidence Center with full data from the documentation workbook.

## V9 — Manual Management & Full-Access Roles
- Added a centralized **Data Management** page for manual add/edit/delete operations without opening the source code.
- Added three principal full-access roles: System Administrator (Hussam Alhussain), Sports Performance Indicator Officer, and Dean.
- Added browser-local persistence for prototype edits using Local Storage.
- Added JSON backup export/import and reset-to-source-data controls.
- Added automatic Audit Log entries for role changes, additions, edits, deletions, imports, and exports.
- Added responsive management modal and generic editors for students, profiles, championships, calendars, opportunities, applications, clubs, evidence, indicator fields, and audit records.
